# Password Strength Checker

A CLI tool that evaluates password strength and provides feedback.

## Features
- Checks length, uppercase, numbers, special characters
- Visual strength bar (████░░░░░░)
- Specific suggestions for improvement
- Strength rating (Weak/Medium/Strong/Very Strong)

## Usage
```bash
python password_checker.py
```

## Requirements
- Python 3.x
